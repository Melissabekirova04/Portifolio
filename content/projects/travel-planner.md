Travel Planner is my backend project for the third semester. The goal is to build an API where users can plan and manage their personal trips.

## Implemented Features

- Weather information for supported airport cities in Scandinavia.
- Account registration and login.
- User persistence with PostgreSQL and Hibernate.
- Protected endpoints that require an authenticated session.

## Technologies

**Java, Javalin, Hibernate/JPA, PostgreSQL and Maven.**
